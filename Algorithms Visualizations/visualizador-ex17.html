Exercício 17 · Lógica & Estruturação Mental Inversor Decimal com Acumulador

Visualizador do Exercício 17

Como inverter qualquer número inteiro sem converter para string ou vetor. Compreenda a mecânica matemática da Base 10 (% 10 e / 10) e a construção mental do pseudocódigo com acumulador.

A Fórmula Mágica da Base 10 REGRAS DE OURO

1. Arrancar último dígito: d = n % 10
2. Encolher o número: n = n / 10
3. Colar dígito no final: acum * 10 + d

Recursão de Cauda Conta feita na IDA!

Laboratório Mental: Como Pensar a Matemática & Estruturar o Pseudocódigo

O método infalível para resolver antes de digitar qualquer código em C

PASSO 1 · A "PINÇA" % 10

Como extrair o último dígito?

Qualquer número dividido por 10 deixa como resto a sua casa das unidades.

Exemplo com 1234:
1234 % 10 = 4
O 4 foi capturado isoladamente!
PASSO 2 · A "TESOURA" / 10

Como descartar o dígito lido?

A divisão inteira em C descarta a fração decimal, "encolhendo" o número em 1 casa.

Exemplo com 1234:
1234 / 10 = 123
O 4 sumiu, restou apenas 123!
PASSO 3 · A "ESTEIRA" * 10 + d

Como anexar o dígito no final?

Multiplicar o acumulador por 10 empurra seus dígitos para a esquerda, abrindo a vaga na unidade para somar o dígito novo.

Tinha 4, chegou o 3:
(4 * 10) + 3 = 43
O 4 virou dezena e o 3 virou unidade!

1. Raciocínio Mental Humano

Pergunta 1: Quando eu sei que acabei?
→ Quando o número original não tiver mais nenhum dígito (n virou 0). Aí devolvo o número que montei.

Pergunta 2: Se ainda tem dígitos, o que faço?
→ Pego a última carta da pilha original (n % 10) e coloco na mesa à direita do que já estava lá (acum * 10 + resto).

Pergunta 3: E o resto?
→ Passo o restante do número (n / 10) e a nova mesa para o próximo passo.

2. Pseudocódigo Universal
Antes do C
função Inverter(n, acum):
// 1. CASO BASE (Parada)
se n == 0 então
retorne acum
// 2. PASSO RECURSIVO
senão
digito ← n % 10
novo_acum ← (acum * 10) + digito
novo_n ← n / 10
retorne Inverter(novo_n, novo_acum)
fim_função
3. Código C (Ex17.c)
Linha a Linha
int inverter(int n, int acum) {
if (n == 0) {
return acum;
} else {
return inverter(
n / 10,
acum * 10 + (n % 10)
);
}
}
Recursão Comum (Ex: Soma de 1 a N) Trabalho na Volta

Como você talvez estava acostumado:

return n + soma(n - 1);

O computador não consegue calcular o total na ida! Ele precisa descer até o caso base e só depois, na volta de cada chamada, realizar a soma +. Cada chamada fica esperando a filha responder para somar.

Recursão de Cauda (Ex17.c - Com Acumulador) Trabalho na IDA!

O Segredo do Ex17.c:

return inverter(n / 10, acum * 10 + (n % 10));

Não há nenhuma conta pendente após a chamada! A conta inteira é calculada antes de chamar a próxima função e passada no argumento acum. Quando atinge n == 0, a resposta já está 100% pronta dentro de acum e apenas "escorrega" de volta limpa!

MESA VISUAL · TRANSFERÊNCIA DE DÍGITOS DA BASE 10
IDA · RECURSÃO ATIVA

Acumulador (acum) acum * 10 + resto

Operação da vez: inverter(1234, 0)
Destino da Chamada: inverter(123, 4)

INSPETOR MATEMÁTICO AO VIVO

Aritmética Inteira em C

1234 % 10 = 4
dígito = 4
2. Encolher Número (/ 10)
1234 / 10 = 123
novo_n = 123
3. Deslocar & Somar
(0 * 10) + 4 = 4
novo_acum = 4
