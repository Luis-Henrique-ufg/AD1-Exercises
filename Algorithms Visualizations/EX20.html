Raio-X: O que EX20.c Realmente Calcula?
1. Semifatorial Ímpar (n!!)

Para números ímpares ($n \in \{1, 3, 5, 7, \dots\}$), a função calcula o Fatorial Duplo:
n!! = n × (n - 2) × (n - 4) × ... × 3 × 1
Por exemplo: $5!! = 5 \times 3 \times 1 = 15$; $7!! = 7 \times 5 \times 3 \times 1 = 105$.

2. O Segredo dos Números Pares (Degrau n - 1)

Na Linha 22, quando $n$ é par, o código faz:
if (n % 2 == 0) return fator(n - 1);
Ele não multiplica nada! Apenas "desce um degrau" para o ímpar anterior.
Portanto, para qualquer $n$ par ($n > 2$), o resultado é idêntico a $(n - 1)!!$:
• $fator(4) = fator(3) = 3$
• $fator(6) = fator(5) = 15$
• $fator(8) = fator(7) = 105$

3. Casos Base Múltiplos (Proteção e Parada)

• Linha 16 (n ≤ 1): encerra a recursão ímpar quando chega em 1 (ou trata entradas ≤ 0), retornando 1.0.
• Linha 19 (n == 2): caso base para o menor par positivo, retornando 1.0 sem precisar descer para 1.
