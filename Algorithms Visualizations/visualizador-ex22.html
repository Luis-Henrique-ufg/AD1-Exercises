Dica de Ouro UNIÃO DE RAÍZES

Nunca faça pai[a] = b! Isso quebraria os subordinados de a. No DSU, unimos os líderes supremos: pai[raizA] = raizB. Assim, todos os membros de ambos os clãs continuam unidos debaixo do mesmo teto!

A Metáfora dos Clãs e Líderes

O Disjoint Set Union (DSU), também chamado de Union-Find, é uma das estruturas de dados mais brilhantes da computação. Imagine uma sociedade onde cada pessoa começa como líder absoluto do seu próprio clã de 1 pessoa só (pai[i] = i).

1. Inicialização

pai[i] = i: Ninguém tem chefe superior a si mesmo. Existem exatamente N famílias independentes.

2. find(x)

Sobe a hierarquia de pais até encontrar o nó que é pai de si mesmo: o Líder Supremo da família de x.

3. unir(a, b)

Se as pessoas têm líderes diferentes, um líder se curva ao outro (pai[raizA] = raizB). Agora os dois clãs viram um só!

Compressão de Caminho (Path Compression)

Sem otimização, uma sequência de uniões pode formar uma linha comprida como uma lista encadeada: 1 → 2 → 3 → 4 → 5. Buscar o líder de 1 exigiria 4 passos!

// O truque de 1 linha que muda tudo: if (pai[x] != x) {
  pai[x] = find(pai, pai[x]); // Atualiza direto para a raiz!
}
return pai[x];

Na volta da recursão, todos os nós por onde a busca passou reescrevem seu ponteiro pai[x] para apontar diretamente para o líder supremo. A árvore alta vira uma estrela achatada de profundidade 1!

Por que pai[raizA] = raizB e NÃO pai[a] = b?

Este é o erro número 1 de iniciantes em DSU! Se você fizer pai[a] = b, você está apenas dizendo que a agora tem b como pai.

❌ Erro Fatal: pai[a] = b

Se a já tinha subordinados abaixo dele e um líder acima dele, ligar a diretamente em b rompe a estrutura da árvore anterior ou perde a raiz verdadeira, gerando ciclos ou clãs fragmentados.

✅ Correto: pai[raizA] = raizB

Primeiro descobrimos os chefes supremos: raizA = find(a) e raizB = find(b). Ao ligar a raiz de A na raiz de B, a árvore inteira de A é anexada como filha da árvore de B! Nenhum subordinado é esquecido.

Tempo Quase-Linear: O(M · α(N))

Com a Compressão de Caminhos, o custo de cada operação de find ou unir é amortizado para praticamente tempo constante O(1).

O termo $\alpha(N)$ é a Função Inversa de Ackermann. Ela cresce tão ridiculamente devagar que, para qualquer número $N$ menor que o número de átomos do universo observável ($10^{80}$), temos:

α(N) ≤ 4   ⟹   Tempo praticamente O(M)!

Estruturação do Pseudocódigo antes da Resolução

Para quem tem dificuldade na estruturação lógica, quebre o problema nos seguintes 4 passos mentais bem definidos:

  1. Definição de Estado: Vetor pai[N + 1] onde cada índice representa uma pessoa.
  2. Caso Base Inicial: Todo elemento $i \in [1..N]$ começa com $pai[i] = i$.
  3. Processamento de Arestas: Para cada par $(a, b)$, encontre os líderes supremos. Se diferentes, faça o casamento dos clãs ligando uma raiz na outra.
  4. Contagem de Invariante: Uma família tem exatamente 1 líder supremo (nó onde $find(i) == i$). Logo, basta contar quantos nós atendem a essa condição!
