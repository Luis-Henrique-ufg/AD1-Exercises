Pulo do Gato Didático MONOTONICIDADE

Como $A, B, C \ge 1$, a função $f(x)$ nunca decresce para $x \ge 0$. Isso permite usar busca binária direto na resposta: se $f(meio) \ge k$, descartamos a metade direita inteira! Se $f(meio) < k$, descartamos a metade esquerda inteira!

O que é Busca Binária na Resposta?

Geralmente a busca binária é ensinada para encontrar um elemento num array ordenado. Mas aqui, não existe array na memória!
O "array" é o conjunto infinito de números naturais $x = 0, 1, 2, 3 \dots$. Como a função polinomial $f(x)$ é estritamente crescente, o predicado f(x) ≥ k tem a forma de uma sequência binária perfeita:
[ FALSO, FALSO, ..., FALSO, VERDADEIRO, VERDADEIRO... ]
A busca binária encontra o primeiro ponto de virada exato onde o predicado se torna VERDADEIRO!

Por que long long é obrigatório?

1. Meta $k \le 10^{10}$: Um int comum de 32 bits estoura em $2 \cdot 10^9$.
2. Termo $A \cdot x^2$: Para $A = 10^5$ e $x = 10^5$, o cálculo gera $10^5 \cdot 10^{10} = 10^{15}$, exigindo 64 bits!
3. Fórmula do Meio: Usamos inicio + (fim - inicio) / 2 em vez de (inicio + fim) / 2 para evitar estouro da soma dos extremos.

Busca Linear vs. Busca Binária:

• Busca Linear: Testar $x = 0, 1, 2 \dots 100.000$ levaria até $100.000$ operações no pior caso.
• Busca Binária: $\lceil \log_2(100.000) \rceil = \mathbf{17}$ iterações!
• Ganho de Performance: Mais de $5.800\times$ mais rápido, garantindo aceitação com 0.00s de tempo de execução no BOCA.
