Variações do Exercício 21 (Desafios do Enunciado)

O que aconteceria se a ATM quisesse entregar o maior ou o menor número de cédulas?

Variação 1: Maior Número de Cédulas S = 22 ➔ 5 NOTAS
// Solução: 1 nota de R$2 e 4 notas de R$5
Saída: 1 4 0 0 0 0 (1×2 + 4×5 = 22)

Prioriza usar as menores denominações (R$ 2, depois R$ 5) até onde for possível, maximizando o total de papéis entregues pelo caixa.

Variação 2: Menor Número de Cédulas S = 22 ➔ 2 NOTAS
// Solução: 1 nota de R$2 e 1 nota de R$20
Saída: 1 0 0 1 0 0 (1×2 + 1×20 = 22)

Abordagem típica de ATM bancária no mundo real: usa a maior denominação possível (R$ 20) para que o cliente receba o menor volume na carteira.
