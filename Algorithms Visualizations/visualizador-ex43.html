Por que existem duas structs: ALUNO e CLASSE?

Em C, uma struct ALUNO funciona como a ficha individual de uma pessoa, agrupando tipos diferentes de variáveis:

typedef struct {
  char nome[21]; // texto (vetor de char)
  int nota;      // inteiro
} ALUNO;

Já a CLASSE é uma "pasta" que guarda até 100 fichas: typedef struct { ALUNO aluno[N]; } CLASSE;. Na main, a variável C representa a turma inteira!

O que acontece na passagem para bubble()?

Ao fazer bubble(C.aluno, n):

  • C.aluno é o vetor de fichas. Passamos o endereço inicial dele.
  • A função recebe ALUNO alunos[]. Dentro do bubble, o nome local do vetor é alunos.
  • Logo, alunos[j] acessa diretamente a ficha completa do aluno na posição $j$! Não precisamos mais escrever C.aluno[j] lá dentro.
  • E ao fazer temp = alunos[j];, o compilador C copia o nome e a nota juntos automaticamente!

A Pergunta Fundamental do vemAntes

A função vemAntes(x, y) responde a uma pergunta direta:
"O aluno X tem o direito de aparecer ANTES do aluno Y na classificação final?"

1º Critério: Notas Diferentes
Se x.nota != y.nota, quem tem a maior nota vem antes (return x.nota > y.nota). Se a nota de X for 10 e Y for 9, retorna true!
2º Critério: Empate de Notas!
Se as notas forem rigorosamente iguais, o primeiro if NÃO é acionado. O código passa para: return strcmp(x.nome, y.nome) < 0;

O Mistério do strcmp < 0

A função strcmp(a, b) compara strings caractere por caractere via código ASCII:

  • negativo (< 0): a vem ANTES de b no dicionário (ex: "andre" antes de "beatriz").
  • zero (== 0): os nomes são exatamente iguais.
  • positivo (> 0): a vem DEPOIS de b no dicionário (ex: "marcos" depois de "joaozinho").

Portanto, strcmp(x.nome, y.nome) < 0 devolve true se e somente se o nome de X for alfabeticamente menor que o nome de Y!

Por que o Bubble Sort usa if (!vemAntes(alunos[j], alunos[j + 1]))?

O ponto de exclamação (!) significa "NÃO".

Se vemAntes(alunos[j], alunos[j + 1]) devolver false, significa que alunos[j] NÃO deveria estar antes de alunos[j + 1]. Ou seja, eles estão fora de ordem!

Nesse momento, !false vira true, acionando a troca com a variável temp. Ao final de todas as passadas, a turma inteira estará perfeitamente classificada, e o último colocado na posição n - 1 é quem tirou a menor nota (ou teve o pior desempate), recebendo a tag #reprovado(a)!
