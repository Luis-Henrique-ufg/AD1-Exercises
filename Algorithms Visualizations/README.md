# 🎨 Visualizadores Interativos de Algoritmos

Este diretório contém visualizadores interativos em **HTML/CSS/JavaScript puro** (single-file, sem dependências externas) desenvolvidos para apoiar o estudo e a compreensão didática de problemas e algoritmos da disciplina de **Algoritmos e Estruturas de Dados 1 (AED 1)** da **Universidade Federal de Goiás (UFG)**, no curso de **Engenharia de Software**.

---

## 🎯 Objetivo

Facilitar a visualização passo a passo do fluxo de execução, estados de memória, chamadas recursivas e estruturas de dados de exercícios cobrados na plataforma BOCA e em sala de aula, transformando código C abstrato em simulações visuais intuitivas.

## 🚀 Como Executar

Cada visualizador é um arquivo HTML autocontido. Para usá-los:

1. Dê um duplo clique no arquivo `.html` desejado (ou clique com botão direito e selecione **Abrir com** $\rightarrow$ seu navegador web favorito: Chrome, Firefox, Edge, etc.).
2. Não é necessário instalar Node.js, servidores locais ou qualquer dependência externa.
3. Utilize os controles de reprodução (Play, Pause, Passo Anterior, Próximo Passo, Slider de Velocidade) para acompanhar a simulação.
